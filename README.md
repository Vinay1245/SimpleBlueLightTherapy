# Simple Blue Light Therapy Device
I created a simple blue light therapy device that allows you to adjust the blue light's brightness and set certain conditions under which it can work. The system uses a photoresistor, thermistor, potentiometer, blue LED, RGB LED, 3 buttons, a buzzer, and a 4-digit 7-segment display. 

Button Functions:
Button 1: Adjust timer in 1-minute increments
Button 2: Start or reset Timer
Button 3: Switch between the different display modes

Using the buttons, you can change the timer, and after starting the timer, you can change the brightness of the blue LED. The RGB LED is there to indicate when there is a medium priority or high priority. When temperature or light levels go past a certain value, the RGB LED either displays yellow or red to indicate the warning and when the LED is red, the blue LED will not shine.
